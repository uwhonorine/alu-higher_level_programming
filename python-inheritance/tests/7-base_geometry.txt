The ``7-base_geometry`` module
==============================

Using ``BaseGeometry``
----------------------

First import ``BaseGeometry`` from the module:

    >>> BaseGeometry = __import__('7-base_geometry').BaseGeometry
    >>> bg = BaseGeometry()

``area`` is not implemented in the base class:

    >>> bg.area()
    Traceback (most recent call last):
    ...
    Exception: area() is not implemented

Valid values
------------

A positive integer is accepted and nothing is returned:

    >>> bg.integer_validator("my_int", 12)
    >>> bg.integer_validator("width", 89)
    >>> print(bg.integer_validator("one", 1))
    None

Big positive integers are accepted:

    >>> bg.integer_validator("big", 10 ** 30)

Values that are not integers
----------------------------

A string raises a ``TypeError``:

    >>> bg.integer_validator("name", "John")
    Traceback (most recent call last):
    ...
    TypeError: name must be an integer

The name given is used in the message:

    >>> bg.integer_validator("my variable", "1")
    Traceback (most recent call last):
    ...
    TypeError: my variable must be an integer

----------------------------------

Zero raises a ``ValueError``:

    >>> bg.integer_validator("age", 0)
    Traceback (most recent call last):
    ...
    ValueError: age must be greater than 0

So do negative integers:

    >>> bg.integer_validator("distance", -4)
    Traceback (most recent call last):
    ...
    ValueError: distance must be greater than 0

    >>> bg.integer_validator("distance", -10 ** 30)
    Traceback (most recent call last):
    ...
    ValueError: distance must be greater than 0

The type is checked before the value:

    Traceback (most recent call last):
    ...
    TypeError: value must be an integer
