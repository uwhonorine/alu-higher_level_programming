The ``1-my_list`` module
========================

Using ``MyList``
----------------

First import ``MyList`` from the module:

    >>> MyList = __import__('1-my_list').MyList

``MyList`` inherits from ``list``:

    >>> issubclass(MyList, list)
    True

An empty list prints as an empty list:

    >>> my_list = MyList()
    >>> my_list.print_sorted()
    []

``print_sorted`` prints the list in ascending order and does not
modify it:

    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]
    >>> print(my_list)
    [1, 4, 2, 3, 5]

A list that is already sorted stays the same:

    >>> my_list = MyList([1, 2, 3])
    >>> my_list.print_sorted()
    [1, 2, 3]

A list sorted in descending order is reversed:

    >>> my_list = MyList([5, 4, 3, 2, 1])
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]

Negative numbers are sorted correctly:

    >>> my_list = MyList([3, -1, 0, -5, 2])
    >>> my_list.print_sorted()
    [-5, -1, 0, 2, 3]
    >>> print(my_list)
    [3, -1, 0, -5, 2]

Duplicates are kept:

    >>> my_list = MyList([2, 1, 2, 1])
    >>> my_list.print_sorted()
    [1, 1, 2, 2]

A list with only one element:

    >>> my_list = MyList([7])
    >>> my_list.print_sorted()
    [7]

Big numbers are sorted too:

    >>> my_list = MyList([10 ** 20, -10 ** 20, 0])
    >>> my_list.print_sorted()
    [-100000000000000000000, 0, 100000000000000000000]

``print_sorted`` prints the list and returns nothing:

    >>> my_list = MyList([2, 1])
    >>> print(my_list.print_sorted())
    [1, 2]
    None

The other ``list`` methods are inherited:

    >>> my_list = MyList([3, 1])
    >>> my_list.extend([2])
    >>> len(my_list)
    3
    >>> my_list.sort()
    >>> print(my_list)
    [1, 2, 3]
    >>> isinstance(my_list, list)
    True

The sorted output is independent of later changes:

    >>> my_list = MyList([2, 1])
    >>> my_list.print_sorted()
    [1, 2]
    >>> my_list.append(0)
    >>> my_list.print_sorted()
    [0, 1, 2]
    >>> print(my_list)
    [2, 1, 0]
